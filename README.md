# Aurora Sun — portfolio

A small editorial portfolio for three projects: [PagePrism](projects/pageprism.html), [Throwaway](projects/throwaway.html), and [SunJobRadar](projects/sunjobradar.html).

The site is static HTML and CSS. Open `index.html` locally or serve this directory with any static file server. GitHub Pages publishes the repository root at `https://aurorasundev.github.io/portfolio/`.

The artwork is an illustrative collage. PagePrism is open source and can be downloaded and run locally; Throwaway has an online experience; SunJobRadar provides an Agent-guided workflow for creating a personal job-search workbench.

The About photograph is used with Aurora's permission. All portfolio copy and site design are part of this repository.
